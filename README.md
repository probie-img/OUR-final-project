# Real Estate Agency Website

## Introduction

This is a simple Real Estate Agency website created as a beginner-level programming project. The website is designed to provide information about properties and the real estate agency in a simple and user-friendly way.

## Purpose

The purpose of this project is to practice the basic concepts of web development using HTML, CSS, and JavaScript.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Simple navigation bar
- Home/Hero section
- Property listings
- Property cards
- About section
- Contact form
- Basic JavaScript interaction
- Simple and clean design

## Website Sections

### Home
The home section introduces the real estate agency and provides a button to explore properties.

### Properties
The properties section displays available properties along with their images, names, locations, and prices.

### About
The about section provides basic information about the real estate agency.

### Contact
The contact section contains a simple form where users can enter their name, email, and message.

## How to Run

1. Download or extract the project folder.
2. Open the project folder.
3. Open the `index.html` file.
4. The website will open in Google Chrome.
5. Make sure `style.css` and `script.js` are in the same folder as `index.html`.
